# 第 40 页

4.5 江汉区

这个区域好吃的太多了，万松园还有江汉路都在这边，吃不过来了，就推荐几

家我觉得很有特色的吧。

（1） 台客台式小吃：台湾美食

这家店的台湾美食味道很地道，推荐这家店的几道美食：<mark class="recommendation">盐酥鸡、甜不</mark>

<mark class="recommendation">辣、卤肉饭、荔枝虾球</mark>。但是这家店是夫妻店，阿姨招待，叔叔一个人做，但

是来的人又不少，所以等餐可能会有点久，建议先到店取号后再去附近逛逛。

台客台式小吃美团信息

（2） 夏氏砂锅（万松园店）

本地人好多都喜欢去，听说很多年夜饭在这边办。之前路过过几次，每次

都排长队。在离开武汉之前，还是抱着好奇心下午很早就过去，终于吃上了，

至少我们点的几个菜，都可以给到夯。推荐几道菜：<mark class="recommendation">锅边馍</mark>（适合粘砂锅里面

的汤汁吃，很好吃）、<mark class="recommendation">莲藕排骨汤、香辣蟹拌面、夏氏古法烤鸭、黄牛肉烧石首</mark>

<mark class="recommendation">鮰鱼肚、珍珠肉丸、不一样的茄子、桂花山药</mark>。
