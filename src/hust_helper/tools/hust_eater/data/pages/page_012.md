# 第 12 页

（4） 杏元餐厅：家常小炒

这家店也比较特殊，我们课题组小团建很喜欢来这边吃饭，甚至有的学长

已经把每一道菜都吃过了。

我先列举下我吃过比较喜欢的菜：<mark class="recommendation">怪味茄子</mark>（我一个不爱吃茄子的都特别

喜欢吃，但是可能是出餐不稳定，我吃过5 次里面有1 次有点偏甜了，其他4

次都没有问题）、<mark class="recommendation">川香辣子鸡</mark>（虽然说我不能吃辣，但是我吃过几块，真的好

吃）、<mark class="recommendation">牛三鲜</mark>（其实我个人觉得这道菜怎么做都不会难吃，但是有点辣，我只能

吃表面的）。

因为学长们毕业已经一年多了，后面没怎么去过，因为离实验室确实有点

儿距离，我只能记住印象中最喜欢的三道菜了，其他的大家可以去探索下。

（5） 土媳妇砂锅（创始店）：湖北菜

之前毕业聚餐，去体验了下，味道确实很nice，可冲。我们点的豌豆排

骨，砂锅牛肉，砂锅牛杂，都挺好吃的，第一个不辣，后面两个微辣，浙江人

表示洒洒水啦。附近还有一家叫土媳妇香锅坊，听说也不错，但是我还没去

过，因为这家确实比较辣，主打炒菜，大家可以去体验下。
