# 第 22 页

2.5 武大周边

武大周边，其实主要就是武大南面的一块商圈和老街，区域就不给出来了。

（1） 赵师傅东北菜

这家店必须给到夯！是我在武汉吃到过最好吃的东北菜。我带东北的朋友

去吃都是清一色好评。之前华科附近也有家东北菜我爱吃，但是出餐不稳定，5

次有至少2 次难吃。但是赵师傅东北菜我去了7 次，每次都特别好吃！

先说几道我最喜欢的菜：<mark class="recommendation">锅包肉</mark>（在武汉吃过最好吃的锅包肉，不吹不

黑）、<mark class="recommendation">东北大拌菜</mark>（每次吃完都觉得意犹未尽，还想再点）、<mark class="recommendation">地三鲜</mark>（炒的真的

很香，朴素的食材能做得这么美味也是一种水平）。之前还点过一次<mark class="recommendation">铁锅炖</mark>，忘

了是啥铁锅炖了，一定要记得给阿姨提前一小时打电话备菜，现场不能点铁锅

炖。其他的菜点就完了，不会难吃。真没有推广的意思，我是真喜欢这家店。

（2） 三顾茅炉：火锅

这家店我看评价挺高的，之前也有武大的朋友给我推荐，就在赵师傅东北

菜边上，但是好几次我过去后没忍住，还是进了赵师傅东北菜，锅包肉真香。

大家伙有空可以去试试三顾茅炉，我看网上推荐最多的是：<mark class="recommendation">牛三鲜火锅</mark>。
