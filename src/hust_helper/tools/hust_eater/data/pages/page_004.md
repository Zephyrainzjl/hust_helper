# 第 4 页

第一章 华科食堂篇

在介绍中，我会一一列举每个食堂有什么吃的，然后对我推荐的好吃的进

行<mark class="recommendation">标红</mark>，特别好吃的会在标红的同时加<mark class="recommendation">黄色底色</mark>。（<mark class="recommendation">特此说明！我没吃过每个窗</mark>

<mark class="recommendation">口，可能会漏掉一些美食，大家可以自己去发现！</mark>）

1.1 华科食堂一览

华科目前有34 个食堂，下面按照东区、中区和西区来对食堂分布区域进行

划分。

首先是12 个东区食堂。目前包含：韵酒一二楼、东园一二三楼、东教工、

学一一二楼、学二一二楼、韵苑11 栋茶咖、东区CBD。

接着是9 个中区食堂。目前包含：东一一二楼、集贤楼一二楼、东华园、

东三、紫荆园、喻园、集锦园。

最后是13 个西区食堂。目前包括：西一一二楼（包含二楼民族窗口）、西

二一二楼、百景园一二三楼、百惠园、西华园、绿园、菘邻里、紫菘食堂、陈

怀民小吃街。

列举完各个食堂，下面将就这些食堂中的美食进行介绍。特此说明，没有

列举到的不代表不好吃，作者仅记录自己吃过的觉得好吃的窗口和菜品。

1.2 东区食堂

（1） 韵酒一楼：

刀削面：很多朋友都反馈刀削面味道不错。

素菜卷饼：位于煎烙窗口

砂锅面：有点微辣

沙拉脆皮鸡、可乐鸡：都位于饮料边上窗口

酥肉小锅：真的是给你一口小锅，味道还不错

馄饨窗口：金牌虾仁馄饨

鲜肉小笼包、红油牛肉包；
