# 第 48 页

5.5 硚口区

（1） 宝善堂

是我最近发现的一家宝藏街，很有武汉烟火气和武汉市井特色（不是贬

义），真的很不错。推荐几家店：<mark class="recommendation">山西手工老面馒头</mark>（推荐<mark class="recommendation">红豆包</mark>）、<mark class="recommendation">北京香酥</mark>

<mark class="recommendation">芝麻饼</mark>（网友推荐他家的<mark class="recommendation">葱香剁饼</mark>）、<mark class="recommendation">星级排条</mark>（我点的牛肉鸡肉双拼，真好

吃）、<mark class="recommendation">邱记锅盔</mark>（万松园之前那家听说很好吃，但是后面关门了，这边的也可以

试试）、<mark class="recommendation">红豆酥</mark>（店名不太记得了，只有他家卖红豆酥，很明显）。

还有好多老式面包店，上次去买了三家的，吃起来都不错。边上还有个夜

市摊，好多小摊，看起来嘎嘎香。

（2） 长堤街

之前看的武汉文旅推荐，去了一次，确实不错，就是小远。推荐几家店：

<mark class="recommendation">桂萍牛杂</mark>（网上其实很多人推荐，但是我去吃了，感觉中上水平吧，没有那么

惊艳，可能是因为我吃不了辣，点的微辣）、<mark class="recommendation">油炸小吃</mark>（吃了个炸鸡腿，挺好吃

的）、<mark class="recommendation">姚姐手工冰粉</mark>（当时桂萍有点辣，去这边买了冰粉，味道确实不错）、<mark class="recommendation">老</mark>

<mark class="recommendation">街鸡汤、和平大排档、曾记水货汤包</mark>（网上推荐番茄味）、<mark class="recommendation">李爹爹冰冻米酒</mark>（按

瓶卖的，也是少见）、<mark class="recommendation">麻木老地方牛杂</mark>（网友推荐的，我没吃过）。

要去的话，导航长堤街油炸小吃。
