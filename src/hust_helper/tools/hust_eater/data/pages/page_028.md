# 第 28 页

3.3 江汉区

（1） 铁棚子热干面

这家店之前很出名，好几次上武汉文旅，我吃过一次，应该是属于<mark class="recommendation">老派热</mark>

<mark class="recommendation">干面</mark>。老派热干面讲究芝麻酱的原汁原味，不会加入额外的汤汁，吃起来会有

点干，但是更香。新派热干面会加入卤汁或者牛肉汤提味，让面吃起来不是那

么干，更容易拌开，但是会冲散芝麻酱的香，融入了别的香味。之前说的汉味

热干面和天声热干面就属于新派热干面。虽然说老派热干面比较干，但是芝麻

酱的味道真的很香，推荐来尝试一下，但是之前没吃过热干面的可能会不太适

应。他家的<mark class="recommendation">面窝</mark>我也很推荐，外圈软糯，中间很脆，特别好吃。

（2） 雪梅鲜鱼糊汤粉店（北湖店）

武汉文旅推荐的，说这家<mark class="recommendation">鱼糊汤粉</mark>很好吃，但是我早上受不了鱼糊汤粉中

的胡椒味道，所以我吃不了。

（3） 严老幺烧麦

武汉文旅推荐的，很火的一家店。网上特别推荐他家的<mark class="recommendation">重油烧麦</mark>和<mark class="recommendation">三鲜豆</mark>

<mark class="recommendation">皮</mark>。我尝试过他家的重油烧麦，和鱼糊汤粉一样，很浓的胡椒味，我早上有点

顶不住，但是味道很香。
